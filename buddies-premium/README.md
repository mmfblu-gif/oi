# Buddies premium

Pacote independente de **Kitsu, Nimbo e Marina**, com desenhos, animações, falas e código de desenho para integração. Não inclui o aplicativo original nem mudanças nele.

- [Baixar o ZIP](https://github.com/mmfblu-gif/oi/raw/refs/heads/main/buddies-premium/buddies-premium-somente.zip)
- [Baixar a prévia animada](https://github.com/mmfblu-gif/oi/raw/refs/heads/main/buddies-premium/previa-buddies.html) — salve e abra no Chrome, Edge ou Firefox atualizado; funciona offline.
- [Ver os personagens](colecao-premium.png)

O ZIP contém nove estados por personagem, 54 folhas de sprites PNG transparentes (normal/suave), desenhos SVG, 57 falas, metadados e fonte C# independente. Cada folha tem 48 quadros de 160 × 160 px. Consulte LEIA-ME.txt dentro do pacote.

O ZIP, os 2.592 quadros e a prévia offline foram verificados. O núcleo C# foi compilado. A integração e a validação no aplicativo Windows ficam com a equipe de desenvolvimento.
